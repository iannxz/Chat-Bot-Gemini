## ✨ Sobre o Projeto

Transforme conversas em experiências inteligentes! Este projeto é a base de um chatbot dinâmico, que usa a API do **Gemini AI** para gerar respostas criativas com contexto — tudo isso em uma interface simples e rápida com **Streamlit**.

---

## 🔧 Requisitos

Para rodar sem dor de cabeça, você vai precisar de:

- ✅ Python 3.10 ou superior  
- ✅ Conta no [Google AI Studio](https://aistudio.google.com/)  
- ✅ Internet ativa (claro, a IA precisa conversar com o mundo!)

---

## ⚙️ Setup Rápido

Clone, instale, configure e converse com a IA em poucos passos:

```bash
# Clone o repositório
git clone https://github.com/iannxz/Chat-Bot-Gemini.git
cd gemini-chatbot

# Crie o ambiente virtual
python -m venv venv

# Ative o ambiente virtual
# Windows:

# Instale as dependências
pip install -r requirements.txt
